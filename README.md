# Festival-sales-dashboard
Analyzes two years (Jan2023–Dec2024) of daily Amazon.in/Flipkart-style sales data, focused on how major Indian sale seasons—Republic Day Sale, Holi Sale, Summer Sale,Independence Day Sale,Big Billion Days/Great Indian Festival,Diwali Sale,Black Friday/Cyber Monday, and the Year-End Sale-move revenue, discounting and returns compared to normal days.
